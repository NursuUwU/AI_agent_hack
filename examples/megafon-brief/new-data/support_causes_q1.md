# Разбор обращений семейных групп о перебоях связи

> Учебные данные команды для демонстрации пересмотра. В брифе их нет, числа вымышлены.

Источник: учёт обращений в поддержку, семейные группы, три последних месяца базового года.

Всего обращений о перебое связи у участника семейной группы: 1 200.
После объединения повторных звонков об одном и том же перебое осталось 830 разных случаев.

| Причина перебоя по записям оператора | Случаев | Доля случаев |
|---|---:|---:|
| Пропущен платёж или недостаточно денег на счёте участника | 382 | 46 % |
| Исчерпана выделенная участнику доля общего пакета | 257 | 31 % |
| Номер оплачен, интернет доступен, устройство выключено или вне сети | 75 | 9 % |
| Прочее и не установлено | 116 | 14 % |

В 481 случае из 830 (58 %) организатор узнал о перебое из просьбы близкого, а не из уведомления оператора.

Ограничение: учтены только клиенты, которые обратились в поддержку. Сколько таких перебоев
прошло без обращения, по этим данным определить нельзя.
