# Ответ владельца системы расчётов

> Учебные данные команды для демонстрации пересмотра. В брифе их нет, условия вымышлены.

1. Остаток общего пакета в системе расчётов обновляется с задержкой до 6 часов.
   Предупреждение о низком остатке, построенное на этих данных, может прийти позже перебоя.
2. Передача интернета участнику доступна на 3 из 5 семейных тарифов. На двух тарифах
   организатор видит остаток, но выделить объём не может.
3. Состояние счёта и результат платежа по номеру участника доступны без задержки,
   если участник разрешил организатору видеть начисления.
4. Доработка системы расчётов для обновления остатка в пределах 15 минут оценена
   в 4 человеко-месяца и может начаться не раньше третьего квартала.
